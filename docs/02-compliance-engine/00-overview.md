# Compliance Engine

Evaluates IEC 62304, ISO 14971, and 21 CFR Part 11 traceability across the 5-stage graph (`HAZARD <-> SPEC <-> WORK <-> TEST <-> SIGNATURE`), computes deterministic blast radius, manages sharded KVS persistence with optimistic locking, ingests live Atlassian artifacts, and maintains a SHA-256 hash-chained audit ledger.

## Files

- [evaluation-rules.md](./evaluation-rules.md) — Deterministic 5-stage evaluation rules & exact violation strings, `evaluateIssueReleaseGate` fail-closed behavior, `computeBlastRadius` / `computeMultiBlastRadius` BFS, sharded KVS (`SHARDED_V2`) with `vlock` & `issueKeyIndex` / `meta_index` O(1) lookups, `LiveIngestionService` resumable `nextPageToken` cursors & `/remotelink` short-circuiting, bounded `AuditLogService.verifyAuditChain`, and `MEDTRACE_PART11_PREVIOUS_SECRETS` / hybrid `ECDSA-P256-SHA256+HMAC-SEAL-V1` Part 11 signatures.

## Core Modules & Test Suites

- [src/types.ts](../../src/types.ts) — Shared browser-safe domain types, `PART11_ATTESTATION_PHRASE`, `AuditActionType`, `AuditAuthMethod`, and `MedTraceResolverMap`.
- [src/crypto-utils.ts](../../src/crypto-utils.ts) — `sha256Hex`, `canonicalJsonStringify`, `isKvsConflictError`, `sanitizeKvsKeySegment`, `measureJsonBytes`, and `validateHttpsUrl`.
- [src/compliance-engine.ts](../../src/compliance-engine.ts) — 5-stage rule evaluation, `HMAC-SHA256-SEAL-V1` (`computePart11Seal` / `verifyPart11Seal` with `MEDTRACE_PART11_PREVIOUS_SECRETS` key-ring rotation via `resolvePart11VerificationSecrets` / `computePart11KeyFingerprint`) & hybrid `ECDSA-P256-SHA256+HMAC-SEAL-V1` (`computePart11ClientChallenge` / `verifyPart11ClientSignature` / `computeClientKeyFingerprint`), `evaluateIssueReleaseGate`, `generateComplianceReport`, `computeBlastRadius`, and `computeMultiBlastRadius`.
- [src/seeder.ts](../../src/seeder.ts) — `SeederService` sharded KVS persistence, optimistic `vlock`, `issueKeyIndex` / `meta_index` O(1) shard lookups (`GetSuiteOptions`), content-hash unchanged shard reuse, `kvs.transact()` / chunked staging, composite `(hazardKey, specId)` `SignedSpecBaseline`, and state mutations.
- [src/ingestion.ts](../../src/ingestion.ts) — `LiveIngestionService` paginated Jira/Confluence ingestion, `LIVE_SYNC_CONCURRENCY_BATCH_SIZE = 5` enrichment with `/remotelink` short-circuiting, resumable `nextPageToken` KVS cursors (`SYNC_CURSOR_KEY_PREFIX`), unreached/other-project link preservation, M:N trace linking, revert non-resurrection, and `avi:confluence:updated:page` drift handling.
- [src/audit-log.ts](../../src/audit-log.ts) — `AuditLogService` SHA-256 hash-chained audit ledger, bounded `verifyAuditChain` (`DEFAULT_VERIFY_MAX_ENTRIES = 500`, `MEDTRACE_AUDIT_VERIFY_MAX_ENTRIES`, `nextFromSeq`), and `kvsAuditStorageAdapter`.
